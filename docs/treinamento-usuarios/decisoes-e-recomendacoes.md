# Decisões e recomendações

## As quatro decisões

| Decisão | Quando |
| --- | --- |
| GO | Requisitos críticos conhecidos e compatíveis |
| GO CONDICIONADO | Há aderência, mas existem pendências a resolver |
| NO-GO | Existe incompatibilidade conhecida |
| MONITORAR | Ainda não há oportunidade aberta, faltam dados, o certame está em andamento ou há acompanhamento pós-homologação |

GO **não** significa chance alta de vitória. PCA forte sem edital publicado é **MONITORAR**.

## Prioridade

As contas e oportunidades são priorizadas como **Alta**, **Média** ou **Baixa**, sempre com os motivos:

```
PRIORIDADE: ALTA
A favor: demanda planejada relevante; produto compatível; data prevista próxima.
Contra: distância elevada.
Dados ausentes: frete real.
Próxima ação: validar capacidade logística.
```

## Formato de uma recomendação

```
RECOMENDAÇÃO: [GO / GO CONDICIONADO / NO-GO / MONITORAR]
Evidências a favor: ...
Riscos/contra: ...
Dados ausentes ou não verificados: ...
Próxima ação: ...
```

**Exemplo — GO CONDICIONADO:** produto compatível e especificação aderente; instalação ainda não validada; frete e atestado técnico pendentes. Próxima ação: validar instalação, frete e atestado antes de decidir participar.

## Cartão de bolso — 8 perguntas

1. É PCA, oportunidade, em andamento ou histórico?
2. O produto está identificado por CATMAT?
3. A classificação é informada ou inferida?
4. Se é histórico, qual é o N?
5. Algum dado está ausente ou não verificado?
6. Isso é cenário ou previsão?
7. A recomendação se explica pelos dados?
8. Qual é a próxima ação — e qual o prazo dela?
