# Bem-vindo ao treinamento

Este treinamento ensina a ler corretamente as informações de compras públicas que o LicitaGym entrega, para você tomar decisões comerciais com segurança.

Ao final, você vai saber:

- diferenciar **planejamento de compra (PCA)**, **oportunidade**, **certame em andamento** e **histórico**;
- separar **fato**, **inferência**, **cenário** e **recomendação**;
- identificar produtos pelo código do governo (**CATMAT**);
- ler taxas de vitória e preços históricos sem tirar conclusões que os dados não sustentam;
- conhecer as fases da licitação e os prazos que não podem ser perdidos;
- entender as recomendações **GO**, **GO CONDICIONADO**, **NO-GO** e **MONITORAR**.

> **A regra que resume tudo:** se o dado prova, afirme. Se sugere, qualifique. Se depende de premissa, é cenário. Se falta, "não disponível". Se falhou, "não verificado".

> Este material orienta a leitura dos dados. Não é parecer jurídico: em casos concretos, consulte um advogado de licitações.
