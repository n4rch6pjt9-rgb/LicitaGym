# Primeiro acesso

Antes de acessar

Confirme com a equipe responsável o endereço oficial do LicitaGym e qual conta você deve utilizar. Se ainda não recebeu acesso, solicite as orientações de entrada antes de começar.

Checklist de acesso

1. Abra o endereço informado pela equipe.
2. Siga o método de autenticação apresentado na tela.
3. Confira se entrou com a conta correta.
4. Identifique a tarefa que pretende realizar e siga para Primeiros passos.

Se não conseguir entrar

Anote a mensagem de erro, o horário e o endereço acessado. Informe à equipe se o problema acontece antes ou depois da autenticação. Se enviar uma captura de tela, oculte dados pessoais e informações confidenciais.

Nunca compartilhe senha, código de verificação ou link de recuperação de acesso.
